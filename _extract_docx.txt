8. Projects Page: Search & Filtering Workflow
Open Projects → Enter keyword / choose filters → Results refresh → Sort → Open Property Detail Page
Advanced search by project name, location or keyword.
Filters such as location, property type, budget range, bedrooms/configuration, carpet area and construction status.
Each result card shows image, name, location, starting price, configuration and status, with a link to the detail page.
Clear-all option and a friendly message when no properties match.
Only properties marked Published in the admin dashboard appear in results.

10. EMI Calculator Workflow
Enter Loan Amount → Interest Rate → Tenure → Calculate → View EMI, Total Interest and Total Payable → Enquire Now
EMI = P × r × (1 + r)^n ÷ ((1 + r)^n − 1), where P is the loan amount, r is the monthly interest rate (annual rate ÷ 12 ÷ 100) and n is the tenure in months.
Inputs: loan amount, annual interest rate and loan tenure (years).
Outputs: monthly EMI, total interest payable and total amount payable.
Values update instantly as the user changes sliders or inputs.
Available as a dedicated page from the main navigation.

15. Important Business Rules & Validations
Only published properties are visible on the public website.
Every property must have a name, location, price and at least one image before publishing.
Uploaded files are restricted by type (images, video, PDF) and size.
Admin area is protected by login and the SSL certificate secures all traffic.
The site is responsive across mobile, tablet and desktop.
Pages are search-engine friendly, with clean URLs and meta titles per property.
Contact numbers and WhatsApp links work from a single configurable setting.

17. End-to-End Example
1) A visitor lands on Home, sees a featured property and opens Projects.
2) They filter by location and budget and open a property detail page.
3) They review floor plans, carpet area, gallery, amenities, map and possession status, and download the brochure.
4) They use the EMI calculator to check affordability.
5) They tap Enquire Now, WhatsApp enquiry or Request Site Visit. The enquiry reaches the client on WhatsApp and in the admin dashboard.
6) The admin follows up and updates the enquiry status. As the project progresses, the admin updates construction status and prices from the dashboard with no code changes.
